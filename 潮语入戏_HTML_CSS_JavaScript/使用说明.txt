潮语入戏 — HTML / CSS / JavaScript 离线版本

1. 解压后用 Chrome、Edge 等浏览器打开 index.html。无需安装 Node.js，无需联网。
2. index.html 是入口；styles.css 是完整样式；app.js 是可运行 JavaScript（包含 React 与组件依赖，无需在线 CDN）；data.js 是词语资料。
3. design.css 保留可编辑的网站设计样式；src/explorer.js 是页面交互的可读 JavaScript；src/local-storage.js 是离线保存逻辑。
4. 管理员编号为 1、2、3、4、5；密码统一为 Goforcreation2026。

离线版的使用范围：
新增词语、作品、海报、音视频与投稿保存到当前浏览器的 IndexedDB。换电脑、换浏览器或清除网站数据后不会共享；投稿也只在同一浏览器管理员入口中显示。
离线版的管理员验证在前端执行，仅供演示。公开运营请使用随附完整原项目的服务器验证和数据库。
这是原网站的独立离线版本，不修改已经发布的网站，不自动同步线上数据。
目前包含原始资料中的 59 个词语、6 部作品及校对提示。缺失的原声、海报、作品基础信息标为待补充。

完整线上项目另见 潮语入戏_网站源码.zip，其中包含 app/api 后端、D1 数据表和 R2 上传服务。
